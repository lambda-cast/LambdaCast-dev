    Formats supportés

    Fichiers acceptés

    .pkl — modèles scikit-learn / statsmodels (pickle)
    .joblib — modèles scikit-learn / XGBoost (joblib)

    Conventions de nommage

    Le nom du fichier détermine le type détecté :
    xgb_* → XGBoost  |  arx_* → ARX
    Tout autre nom → Modèle générique

    Fonctionnalités requises

    Les modèles doivent accepter 5 variables d'entrée :
    Solar_Radiation_Wm2, Outdoor_Temp_C, Wind_Speed_ms, Humidity_pct, AQI_US

    Taille maximale

    200 Mo par fichier

    Importer un modèle
    Formats acceptés : .pkl, .joblib (max 200 Mo)
    Laissez vide pour utiliser le nom du fichier. Si un modèle du même nom existe déjà, cochez l'option ci-dessous.
    Supprimer le modèle
    Êtes-vous sûr de vouloir supprimer le modèle ?

    Il ne sera plus disponible dans le moniteur d'installation. Cette action est irréversible.
